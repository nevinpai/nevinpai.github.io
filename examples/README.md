# Examples

Reference copies of the placeholder content the site started with. Nothing in
this folder is built or published; the site only reads `src/`.

- `sample-post.md`: a post showing headings, code, images, footnotes and `draft: true`.
  Copy it into `src/posts/` as `YYYY-MM-DD-title.md` to use it.
- `publications.yaml`, `projects.yaml`: example entries with every field filled in.
- `index.md`, `research.md`: the original placeholder intro and research overview.
